# 報告建議結構

每週報告涵蓋兩個獨立 Case，各自完整分析。共用封面與結語。
不需要機械式照抄標題；可依 Case 調整，但每個 Case 都必須保留「多元觀點、辯證、延伸、綜合觀點」四個核心。

## 封面

- 課程 / 週次（可由檔名或內容推定）
- 組別（有資料才填）
- 日期

## Case 1：{{CASE_1_TITLE}}

### 一、Case 背景與核心問題

用約 2–4 段建立足夠情境。
只保留後續分析需要的事實，不做逐段摘要。

### 二、關鍵利害關係人與衝突結構

說明各方目標、限制、權力、資訊與彼此依賴。
必要時可用簡短表格。

### 三、核心爭點與多元觀點

通常 3–5 個爭點。
每個爭點都要呈現至少兩個合理立場，不把反方寫成稻草人。

### 四、討論與辯證

這一節是高權重。
不是重複「A 說什麼、B 說什麼」，而是要寫出：

- 某觀點提出後，另一觀點挑戰了哪個假設？
- 哪個證據或限制使原本判斷需要修正？
- 有沒有從二選一走到第三方案？
- 哪些分歧仍無法完全消除？

### 五、延伸議題

至少兩個。
可連結理論、制度設計、治理、倫理、權力、激勵、資訊不對稱、跨部門合作、文化差異、危機管理等。

### 六、本組綜合觀點與建議

提出「有條件的判斷」。
包含：

- 目前傾向
- 理由
- 執行條件
- 風險
- 失效條件 / 備案

可對兩個 Case 各給一句最值得帶走的管理洞見，但不要刻意強行串聯。
